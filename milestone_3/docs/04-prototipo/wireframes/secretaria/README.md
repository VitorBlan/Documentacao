# Wireframes da secretária (T-SEC)

Fábrica de Software I · Protótipo em alta fidelidade · Desktop 1440×900 · Perfil Secretária (ACT-01)

Estes wireframes mostram as telas da secretária, o perfil que mais usa o sistema: o Painel, os cadastros de clientes e veículos, o histórico do veículo, os orçamentos, as ordens de serviço e a agenda dos boxes. As áreas seguem a ordem do [site map](../../site-map.md).

## Painel

O Painel é a primeira tela depois do login. Reúne o que a secretária precisa acompanhar no turno: quatro indicadores, as ordens de serviço em andamento, os veículos prontos para retirada e a agenda do dia nos boxes. A navegação está modelada no [IFML-01](../../ifml/README.md#ifml-01-acesso-e-painel).

## Orçamentos

Estes wireframes mostram o ciclo do orçamento, do registro do problema relatado à autorização do serviço: o histórico de orçamentos, a criação, a montagem com serviços e mecânico, a decisão do cliente e os filtros por status. O orçamento aprovado é o ponto de partida da ordem de serviço. A navegação está modelada no [IFML-05](../../ifml/README.md#ifml-05-orçamentos). O fluxo completo, de ponta a ponta, usa o orçamento ORC-1043 do cliente Antônio Ribeiro Sales.
